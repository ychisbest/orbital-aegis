Orbital Aegis is a neon orbital-defense arcade game: swing a shield ring around a planet to shatter incoming meteors and catch golden energy orbs, chaining blocks to raise your combo multiplier while the planet's hull holds out. Survive all ten escalating waves to win — every graphic is drawn in code on a canvas and every sound is synthesized with WebAudio, so it plays offline with no assets and no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080

Controls: mouse, arrow keys or A/D swing the shield · Space or click starts · P pauses · M mutes.
